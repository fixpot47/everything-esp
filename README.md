# Flame Highlight (Minecraft 26.2 Fabric)

Client-side mod by fixpot47. Enlarges orange FlameParticle sprites and forces full brightness so the small flame from the screenshot is more visible.

### Features
- Only flame particles, not smoke, lava, sparks or other particle classes
- Click Mod Menu > Flame Highlight > Config to toggle the effect
- Enabled setting saved to config/flame-highlight.json
- No server installation needed

### Requirements
- Minecraft 26.2, Java 25, Fabric Loader 0.19.3+
- Mod Menu 20.0.3 (required for the settings button)

### Building
Use JDK 25 and Gradle 9.5.1, then run `gradle build`. The JAR is under `build/libs/`.
